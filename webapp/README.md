# 教會敬拜 PPT 產生器 — 網頁版

把歌詞貼上 → 右邊即時看到每一頁的樣子 → 一鍵匯出 PPT。
所有排版都用「積木」組合：**布景積木**（背景圖／底色／遮罩）＋**字體積木**（標題／段落／歌詞的字型、大小、顏色、位置）。
選一塊布景 + 一塊字體 = 一個版型，隨時互換，改一塊、所有用到它的歌一起變。

## 怎麼啟動

**方法一（最簡單）**：雙擊專案根目錄的 `run_web.bat`，會自動開瀏覽器。

**方法二（指令）**：
```bash
# 第一次要先裝套件
.venv\Scripts\python.exe -m pip install -r webapp\requirements.txt
# 啟動
.venv\Scripts\python.exe run_web.py
```
啟動後開 http://127.0.0.1:8000 （只綁本機，不對外）。

## 主要操作

- **左側**：歌曲清單（＋新增、▲▼ 排序、✕ 刪除）、歌名、歌詞、選布景／字體積木。
- **右側**：目前這首歌每一頁的即時預覽（用同一組換算，畫面≈成品）。
- **上方按鈕**：
  - `🧱 積木庫`：管理／新增／複製／刪除布景與字體積木。
  - `📂 讀專案` / `💾 存專案`：存讀整個歌單（含所用積木）。
  - `↩ 匯入舊資料`：把舊版 `ppt_settings.json`（或更舊的 `songs.json`）整包搬進來，背景圖也會一起複製。
  - `⬇ 匯出 PPT`：產生 `.pptx` 下載。

歌詞格式（跟舊版一樣，用中括號分頁）：
```text
[Verse]
我感覺主恩膏充滿我們中間
神的聖靈正在運行
[Chorus]
新酒澆灌帶下新鮮恩膏
說不盡的喜樂充滿我
```

## 幾個重點

- **中文字型**：匯出時會同時設定 East Asian 字型，中文不會再掉回 PowerPoint 預設字（修掉舊版「字體在別台電腦不吃」的問題）。字型名稱要跟目標電腦上的 PowerPoint 一致（預設「微軟正黑體」在 Windows 都有）。
- **預覽 vs 成品**：預覽用瀏覽器畫，跟 PowerPoint 不是同一個引擎，換行可能有一點點差（約 90% 接近）。這種置中文字＋背景圖的版型已經很準。
- **自動存檔**：每次改動會自動存到 `webapp/data/session.json`，重開瀏覽器會還原。正式歌單請用「💾 存專案」另存。
- 舊版桌面程式 `main.py` 完全沒有更動，兩邊可以並存。

## 資料放哪

```
webapp/data/
  uploads/     背景圖
  projects/    你存的專案
  session.json 自動存檔
```
