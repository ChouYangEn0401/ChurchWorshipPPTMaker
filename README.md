## 使用教學
1. 雙擊 exe 打開
2. 選擇最下方讀取專案
3. 選擇 ppt_settings.json (這是我存的檔案)
***使用者透過"儲存專案"未來也可以生成***
4. 點擊 "生成 PPT" 然後選擇儲存位置

## 簡易導覽
分頁： 代表每一首新歌

所有歌詞： 直接貼上去，中間有空白也沒關係，每個分行在ppt內就會如實顯示
```text
[Verse]
我感覺主恩膏充滿我們中間
神的聖靈正在運行
[Pre-Chorus]
今天是主所命定的日子
自由的時刻已來到
[Chorus]
新酒澆灌帶下新鮮恩膏
說不盡的喜樂充滿我
```
字幕顏色設定:
 - 目前"字體"就只有輸入版本，有時候因為作業系統會不支援，此部分建議到PPT中自行修改
 - 目前"白色小框框"是調色盤： (左鍵)可選常用色；(右鍵)可以直接無限制選顏色；選完後再小框框上面移動滑鼠就會更新顏色；沒有就是他秀逗了
 - 目前"歌詞位置調整"： (左0) 就是不留空間，0.05會留一點點，不要亂打負數會壞掉喔；距離上邊可以也不要打負的
 - 目前"選擇背景圖片"： 圖片遺失生成PPT的時候會提醒，重新加入即可

***每個功能都可以自己玩玩看喔~***
