# ⛪ 教會敬拜 PPT 產生器

敬拜團在 Google 文件排好歌 → 這裡一鍵匯入 → 挑背景、看預覽 → 匯出 PPT。

- **網頁版**：在自己電腦上打開就能用；想讓同工用手機一起改，按一下就開出一個 Cloudflare 臨時網址（不用帳號、免費）。
- **像資料庫一樣記下來**：每首歌的歌詞、歌序、用過的背景和排版，每一份做過的 PPT，都留著。下次同一首歌直接沿用上次的樣子。
- **匯出的 PPT 好改**：背景放在投影片母片裡，之後在 PowerPoint 換一張圖，整首歌的每一頁一起換。

> 以前的桌面版（`main.py`）還在，說明放在最下面。

## 開始用（Windows）

在專案資料夾裡，**雙擊 `run_web.bat`**，瀏覽器會自動打開 <http://127.0.0.1:8788>。
第一次會先自動安裝（建立 `.venv`、裝套件、建資料庫，大約 1～2 分鐘）。**關掉黑色視窗就會停止。**

| 專案資料夾裡的檔案 | 做什麼 |
|---|---|
| `run_web.bat` | 打開網頁版（只有這台電腦能用） |
| `run_web_public.bat` | 打開網頁版 ＋ Cloudflare 對外連結（同工用手機一起編輯；要先在「設定」設團隊密碼） |
| `run_web.py` | 同上的 Python 入口：`python run_web.py`、`python run_web.py web --public`、`python run_web.py --help` |
| `run.bat` | 舊的**桌面版**（`main.py`），跟網頁版無關 |

`scripts\windows\` 裡還有分開的 `1-install.bat`（只安裝）、`2-start.bat`、`3-open-public.bat`、`backup.bat`。

| 我要… | 怎麼做 |
|---|---|
| 做這週的 PPT | 首頁 →「從 Google 文件匯入」→ 讀取文件 → 建立歌單 → 挑背景 → 右上角「匯出 PPT」 |
| 讓同工從手機一起改 | 「設定」→ 設團隊密碼 →「開啟對外連結」→ 把網址傳到 LINE 群組；或直接雙擊 `run_web_public.bat` |
| 找以前的 PPT | 「匯出紀錄」→ 下載 |
| 看某首歌以前怎麼唱 | 「詩歌庫」→ 點那首歌：唱過的日期、歌序、背景都在；改過的歌詞舊版本也在 |
| 備份 | 「設定 → 資料 → 現在備份」，或雙擊 `scripts\windows\backup.bat` |
| 搬桌面版的舊資料進來 | 首頁（或「設定 → 資料」）→「匯入桌面版存檔」 |

需要：Windows 10 以上、Python 3.11 以上（`1-install.bat` 找不到會帶你去下載）。
要開對外連結的話另外要 `cloudflared`：打開命令提示字元輸入 `winget install --id Cloudflare.cloudflared`。

## 每週的流程

1. **敬拜團寫文件**：主領在 Google 文件寫好日期、服事同工，下面一個表格放 **歌名／調性／歌序／歌詞**（跟平常一樣）。
2. **匯入**：網址第一次貼上後會記住，之後每週按「讀取文件」→ 看一遍 →「建立歌單」。
   - 詩歌庫有的歌：自動套上次用的背景和排版。
   - 新歌：先用前一首的，挑一下就好。
   - 文件改了？歌單左上角「從文件更新」，已經挑好的背景和排版會保留。
3. **調整**：左邊選歌，中間改歌名／歌序／歌詞，右邊即時看到每一頁（跟 PPT 用同一套規則算字級和折行）。每個改動都自動存。
4. **匯出**：右上角「匯出 PPT」。這次用的歌詞、歌序、背景、排版會存回詩歌庫，PPT 檔留在「匯出紀錄」。

### 歌詞和歌序怎麼寫

```text
[主]
從日出到日落 我要歌頌你的大能
並在列邦中述說你的同在

我要跳舞讚美祂 擊鼓彈琴向祂歡呼      ← 同一段裡空一行 = 換下一頁
[副前1]
右手舉起來 左手舉起來
```

- `[段落名]` 自己一行開始一個段落；Google 文件裡寫 `主：`、`副前1：`、`橋` 也會自動認出來。
- 歌序例如 `主 主 副前1 副 主 副前1 副 副前2 副 副`：投影片就照這個順序排，重複唱的段落重複放，操作的人一路按下一頁。
  主＝主歌＝Verse、副＝副歌＝Chorus、橋＝Bridge；`尾*2` 只放一頁（備忘稿寫 ×2）；前奏、間奏、自由放一張只有背景的空白頁。
- 一行太長會從**空白處**折行（歌詞的句讀）；只差一點點放不下時整頁縮小一點，不會讓一兩個字掉到下一行。

### 在 PowerPoint 裡換背景

匯出的 PPT 每個背景是一個版面配置「背景：xxx」。**檢視 → 投影片母片** → 選「背景：xxx」→ 背景格式 → 換圖片，用到它的每一頁一起換好，暗色遮罩也保留。每一頁的備忘稿寫著「歌名｜段落」。

## 讓同工一起編輯（對外連結）

- 伺服器只綁在 `127.0.0.1`：區網、外面都連不進來，只有透過 Cloudflare 臨時網址。
- 在**這台電腦**上用不需要登入；**從網址進來的人**要輸入團隊密碼（還沒設密碼時，外面的人一律擋掉）。
- 每個人登入時填名字，畫面上看得到「誰最後改了哪首歌」。兩個人同時改同一首，後存的人會看到提醒和最新內容，不會默默蓋掉別人的。
- 關掉對外連結（或關掉黑色視窗）網址就失效、所有人登出；下次開是新網址。
- 開對外連結、改密碼、備份、匯入舊資料只能在這台電腦上做。

做法參考 CloudServicesPlatform（Host 檢查、CSRF、登入次數限制、`__Host-` cookie），讀 Google 文件的方式參考 LINEBotForChurch 讀 Google Sheet（公開連結、不需要金鑰）。

## 資料在哪裡

全部在專案資料夾的 `data\`（已經在 `.gitignore`，不會上傳）：

| 路徑 | 內容 |
|---|---|
| `data\worship.db` | 詩歌庫、歌單、背景、排版、匯出紀錄（SQLite） |
| `data\images\` | 背景圖（同一張圖只存一份；太大的自動縮到 2560px；WebP 等格式轉成 JPG/PNG） |
| `data\exports\` | 每一份匯出過的 PPT |
| `data\logs\` | 執行紀錄、cloudflared 紀錄 |

換電腦：把整個 `data` 資料夾複製過去就好。備份會打包成 zip 放在專案旁邊的 `backups\`。

## 桌面版（舊版，main.py）

桌面版還是可以用：雙擊 `run.bat`（或用 `main.spec` 打包成 exe）。它的存檔 `ppt_settings.json` 可以整包匯入網頁版。

### 使用教學
1. 雙擊 exe 打開
2. 選擇最下方讀取專案
3. 選擇 ppt_settings.json (這是我存的檔案)
***使用者透過"儲存專案"未來也可以生成***
4. 點擊 "生成 PPT" 然後選擇儲存位置
5. 生成前可先按 "預覽" 看每一頁的排版效果

### 簡易導覽
分頁： 代表每一首新歌
 - 分頁上會直接顯示歌名，打字時即時更新
 - 點分頁右邊的 **✖** 就能關閉該分頁
 - "新增歌曲" 會沿用目前這首的字型/顏色/背景設定，但歌名與歌詞留空

所有歌詞： 直接貼上去，中間有空白也沒關係，每個分行在ppt內就會如實顯示
```text
[Verse]
我感覺主恩膏充滿我們中間
神的聖靈正在運行
[Pre-Chorus]
今天是主所命定的日子
自由的時刻已來到
[Chorus]
新酒澆灌帶下新鮮恩膏
說不盡的喜樂充滿我
```
字幕顏色設定:
 - 目前"字體"就只有輸入版本，有時候因為作業系統會不支援，此部分建議到PPT中自行修改
 - 目前"白色小框框"是調色盤： (左鍵)可選常用色；(右鍵)可以直接無限制選顏色；選完後框框會即時變成該顏色
 - 目前"歌詞位置調整"： (左0) 就是不留空間，0.05會留一點點，不要亂打負數會壞掉喔；距離上邊可以也不要打負的
 - 目前"選擇背景圖片"： 圖片遺失生成PPT的時候會提醒，重新加入即可

***每個功能都可以自己玩玩看喔~***
