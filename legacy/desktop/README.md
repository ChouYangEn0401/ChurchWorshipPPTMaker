# 桌面版（舊版，tkinter）

> 這是網頁版出來之前的桌面程式，已經不再開發，留著備查。
> 平常請用專案資料夾裡的 `run.bat`（網頁版）。

這個資料夾裡有：

| 檔案 | 內容 |
|---|---|
| `main.py` | 桌面版程式（tkinter） |
| `main.spec` | 用 PyInstaller 打包成 exe 的設定（在這個資料夾執行 `pyinstaller main.spec`） |
| `ppt_settings.json`、`pic1~4.png`、`background.jpg` | 當初的存檔和背景圖 |
| `songs.json` | 更舊的存檔格式 |
| `worship_output.*`、`敬拜歌單.pdf`、`README.pdf` | 當初做出來的成品備份 |

**把桌面版的資料搬到網頁版**：網頁版「設定 → 資料 → 匯入桌面版的存檔」（預設就是讀這個資料夾的 `ppt_settings.json`），
歌詞會進詩歌庫、背景圖進背景庫、字型設定變成排版。

**還想跑桌面版**：先雙擊專案資料夾的 `run.bat` 安裝一次（會建立 `.venv`），然後在專案資料夾執行：

```bat
.venv\Scripts\python.exe legacy\desktop\main.py
```

---

## 使用教學
1. 雙擊 exe 打開
2. 選擇最下方讀取專案
3. 選擇 ppt_settings.json (這是我存的檔案)
***使用者透過"儲存專案"未來也可以生成***
4. 點擊 "生成 PPT" 然後選擇儲存位置
5. 生成前可先按 "預覽" 看每一頁的排版效果

## 簡易導覽
分頁： 代表每一首新歌
 - 分頁上會直接顯示歌名，打字時即時更新
 - 點分頁右邊的 **✖** 就能關閉該分頁
 - "新增歌曲" 會沿用目前這首的字型/顏色/背景設定，但歌名與歌詞留空

所有歌詞： 直接貼上去，中間有空白也沒關係，每個分行在ppt內就會如實顯示
```text
[Verse]
我感覺主恩膏充滿我們中間
神的聖靈正在運行
[Pre-Chorus]
今天是主所命定的日子
自由的時刻已來到
[Chorus]
新酒澆灌帶下新鮮恩膏
說不盡的喜樂充滿我
```
字幕顏色設定:
 - 目前"字體"就只有輸入版本，有時候因為作業系統會不支援，此部分建議到PPT中自行修改
 - 目前"白色小框框"是調色盤： (左鍵)可選常用色；(右鍵)可以直接無限制選顏色；選完後框框會即時變成該顏色
 - 目前"歌詞位置調整"： (左0) 就是不留空間，0.05會留一點點，不要亂打負數會壞掉喔；距離上邊可以也不要打負的
 - 目前"選擇背景圖片"： 圖片遺失生成PPT的時候會提醒，重新加入即可

***每個功能都可以自己玩玩看喔~***
